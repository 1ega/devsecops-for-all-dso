# Detections

Detection content for security operations belongs here. Future packs can be grouped by engine, such as `sigma/`, `yara/`, `falco/`, and `osquery/`.

A detection should include the rule, sample events or files, expected matches and non-matches, tuning notes, and its source and license. Keep environment-specific values out of shared rules.

**Status:** Structure only; no detection packs are published yet.
