# OWASP ZAP

[ZAP](https://github.com/zaproxy/zaproxy) configurations for baseline, full, and OpenAPI-driven API scans, with rule tuning (`rules.tsv`) and authentication contexts.

Scan only environments you are authorized to test, such as staging. Document rate limits and the accounts used for authenticated scans.

Related skills: [dast-scanning](../../skills/appsec-testing/dast-scanning/SKILL.md), [security-dast](../../skills/appsec-testing/security-dast/SKILL.md).
