# Semgrep rule packs

Keep substantial rule collections in one directory per pack, with their own usage, tests, provenance, and license information.

| Pack | Coverage |
| :--- | :--- |
| [mobile_custom](mobile_custom/README.md) | Android, iOS, React Native, and Flutter |

The smaller [Python starter rules](../rules/README.md) predate this layout and remain available in `rules/`. Future packs can be added here without changing their existing paths.
