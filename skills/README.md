# AI skills

Reusable instructions for AI coding agents. Each directory contains a self-contained `SKILL.md` with a name and description for discovery.

| Skill | Use it for |
| :--- | :--- |
| [authorized-pentest](authorized-pentest/SKILL.md) | Planning and carrying out a scoped, authorized assessment and reporting evidence |
| [secure-code-review](secure-code-review/SKILL.md) | Reviewing code changes for security and quality defects with actionable findings |

For Codex, copy a skill directory into your Codex skills folder and restart or refresh skill discovery. For another agent, include the `SKILL.md` as task instructions. These files do not grant access to targets or replace a written assessment scope.
